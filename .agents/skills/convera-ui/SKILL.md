# CONVERA UI/UX Design System Skill (CCDS v2.0)

## Design Tokens & Layout Rules
- **Color Palette:** Obsidian Dark Mode (`bg-neutral-950`, `bg-neutral-900`, `border-neutral-800`, `text-neutral-100`).
- **Accents:** Emerald/Teal (`emerald-500`) for validated items, Amber (`amber-500`) for assumptions/risks, Rose (`rose-500`) for contested/invalidated decisions.
- **Button Alignment:** Always use `whitespace-nowrap inline-flex items-center justify-center gap-1.5` with calibrated icons (`w-3.5 h-3.5` or `w-4 h-4`) to prevent awkward vertical text wrapping.
- **Navigation:** Command Deck with Stage Anchors, Session Badges, and Traceability Drawers.
